# 대시보드 수업 차트 기획

- 기능 ID: dashboard-charts
- 상태: 확정
- 최종 갱신: 2026-10-22
- 작업계획: [계획](../plans/dashboard-charts.md)
- 현재 기능 문서: [대시보드](../features/dashboard-ui.md), [그룹수업 시간표](../features/class-schedule.md)
- 관련 기준: [UI 가이드](../architecture/ui-guide.md)

## 목적 및 범위

대시보드(`/`)에서 이번 주 수업 운영 현황을 한눈에 보도록 차트 2개를 추가한다. 데이터는 이미 있는 그룹수업 시간표(회차)만 사용한다. 회원·매출 등 아직 없는 데이터나 예시 값은 표시하지 않는다.

## 화면 및 동작 제안

1. 위치: 현재 '워크스페이스 현황' 패널의 빈 상태(데이터 연결 전)를 차트 2개로 바꾼다. PC는 두 차트를 나란히, 992px 미만은 위아래로 배치한다.
2. 차트 1 — 이번 주 요일별 수업 수: 월~일 세로 막대. 오늘 요일은 강조한다. 휴강은 같은 막대에 쌓아서(정상 / 휴강) 구분한다.
3. 차트 2 — 강사별 담당 수업 수(이번 주): 강사 이름 가로 막대, 많은 순 정렬. '강사 미정'도 한 줄로 표시한다. 휴강은 차트 1과 같은 방식으로 쌓는다.
4. 기간: 두 차트 모두 오늘이 속한 주(월~일, 한국 시간)다. 주 이동은 제공하지 않는다(필요하면 '수업 시간표'로 이동하는 링크를 둔다).
5. 집계 기준: 삭제된 회차는 제외한다. 지난 회차와 앞으로의 회차를 모두 센다.
6. 각 막대에 마우스를 올리면 툴팁으로 정확한 수를 보여준다. 막대 끝에 숫자 라벨도 표시해 툴팁 없이도 읽을 수 있게 한다.
7. 상태: 불러오는 중에는 스켈레톤, 실패하면 오류와 다시 시도, 이번 주 수업이 없으면 빈 상태 문구와 '수업 시간표' 링크를 보여준다.

## 데이터·권한 및 예외

- 기존 `GET /api/classes/sessions?from&to`(활성 직원만, 삭제 회차 제외)를 그대로 사용하고 화면에서 집계한다. 새 API·DB 변경은 없다.
- 대시보드는 모든 활성 직원이 보며, 강사 이름 노출 범위는 기존 수업 시간표와 같다.
- 차트는 색만으로 정보를 전달하지 않는다(숫자 라벨·범례·접근성용 요약 텍스트 또는 표 제공).

## 완료 기준

- [ ] 이번 주 회차가 있을 때 요일별 막대 7개가 표시되고 각 수(정상·휴강)가 실제 회차 수와 일치한다. 오늘 요일이 구분된다.
- [ ] 강사별 막대가 많은 순으로 표시되고 '강사 미정' 회차는 '강사 미정' 줄로 집계된다.
- [ ] 삭제된 회차는 어느 차트에도 포함되지 않는다.
- [ ] 이번 주 회차가 0건이면 두 차트 대신 빈 상태와 수업 시간표 링크가 보인다.
- [ ] 조회 실패 시 오류와 다시 시도가 보이고 다시 시도로 회복된다.
- [ ] 1440·768·390px에서 페이지 가로 스크롤 없이 표시되고, 키보드·스크린 리더로 수치를 확인할 수 있다.
- [ ] 기존 대시보드 E2E(레이아웃·메뉴)가 통과하고 린트·타입·빌드·리뷰·문서 갱신을 마친다.

## 확정 사항 (2026-10-22 사용자 확정)

1. 차트 라이브러리는 `@mantine/charts`(내부 recharts)를 추가한다.
2. 강사별 차트 기간은 이번 주다.
3. 휴강은 막대에 쌓아 정상 수업과 구분한다.
4. 기존 '워크스페이스 현황' 빈 상태 패널을 '이번 주 수업 현황' 차트 패널로 대체한다.
