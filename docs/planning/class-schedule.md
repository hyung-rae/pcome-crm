# 그룹수업 시간표 관리 기획

- 기능 ID: class-schedule
- 상태: 확정
- 최종 갱신: 2026-10-22
- 작업계획: [계획](../plans/class-schedule.md) — 확정
- 현재 기능 문서: 미구현

## 목적 및 사용자

헬스장 직원(관리자·서브관리자)이 GX 그룹수업(요가·필라테스·스피닝 등)의 종류와 주간 시간표를 CRM에서 등록·조회·변경한다. 종이·메신저로 관리하던 시간표를 한곳에 모으고, 같은 강사의 시간 겹침과 휴강 누락을 줄이는 것이 목적이다.

## 범위

포함:

- 수업 종류 관리: 이름, 기본 정원, 기본 소요시간, 표시 색상, 사용 여부
- 강사 지정: 기존 직원 계정에 '강사 여부'를 표시하고 수업에 강사를 지정
- 시간표 관리: 매주 반복 수업과 특정 날짜의 단발 수업 등록·수정·휴강
- 시간표 조회: PC·태블릿은 주간 그리드, 모바일은 날짜별 목록. 주 단위 이동

제외(후속 기능으로 별도 기획):

- 회원 예약·참석·대기, 회원 정보(members 테이블)
- PT(1:1) 일정, 공간(스튜디오·룸) 관리
- 월간 달력 보기, 회원 대상 시간표 공개
- 문자·푸시 알림, 공휴일 자동 휴강, 강사 급여·수업 통계
- 대시보드 '오늘의 수업' 표시
- 새 직원 역할 추가와 기존 권한 구조 변경

## 사용자 흐름

1. 직원이 LNB의 '수업 시간표'(`/classes`)로 들어가 이번 주 시간표를 본다.
2. 처음에는 같은 화면의 '수업 종류' 탭에서 수업 종류(예: 요가, 기본 정원 20명, 50분)를 등록한다.
3. 관리자가 직원 관리에서 수업을 맡는 직원에게 강사 표시를 한다.
4. 시간표에서 수업을 추가한다. 수업 종류·강사·시작 시각을 고르고 반복(요일·시작일·종료일 선택) 또는 단발(날짜)을 정한다. 정원·소요시간은 수업 종류의 기본값으로 채워지고 바꿀 수 있다.
5. 저장 시 같은 강사의 겹치는 수업이 있으면 저장하지 않고 겹치는 일정을 안내한다.
6. 회차를 눌러 상세를 보고 수정·휴강한다. 반복 수업은 '이 회차만' 또는 '이후 전체'를 선택한다.

## 화면 및 동작

- 진입: LNB 메뉴 '수업 시간표' 1개. 화면 안에서 '시간표'·'수업 종류' 탭을 전환한다
- 시간표(PC·태블릿): 월~일 × 시간 그리드. 회차 블록에 수업명·시간·강사·정원을 표시하고 수업 종류 색상을 쓴다. 휴강 회차는 흐리게 '휴강' 표시. 이전·다음 주, 오늘로 이동
- 시간표(모바일): 선택한 주의 날짜별 회차 목록
- 필터: 수업 종류, 강사
- 수업 추가·수정: 기존 Modal 패턴. 반복이면 요일 다중 선택, 시작일 필수, 종료일 선택(비우면 계속 반복)
- 반복 회차 수정·휴강 시 범위 선택: 이 회차만 / 이 회차 이후 전체. 지난 회차는 바뀌지 않는다
- 수업 종류 관리: 목록·추가·수정·사용 중지. 기존 직원 관리 목록과 같은 표·더보기 메뉴 패턴
- 직원 관리: 관리자 화면의 직원 행에 강사 여부 표시·변경 추가. 강사 해제·비활성화·삭제 확인창에 앞으로 맡은 회차 수 경고 추가
- 지난 회차는 상세 조회만 되고 수정·휴강·삭제 버튼을 표시하지 않는다
- 로딩·빈 상태(수업 종류 없음, 해당 주 수업 없음)·오류·중복 제출 방지는 [UI 공통 가이드](../architecture/ui-guide.md)와 기존 패턴을 따른다

## 데이터 및 권한

개념 데이터(테이블·컬럼 상세는 작업계획에서 확정):

| 데이터 | 내용 |
|---|---|
| 강사 여부 | staff에 강사 여부 값 추가. 역할(admin·sub_admin)은 그대로 둔다 |
| 수업 종류 | 이름(사용 중인 종류끼리 중복 불가), 기본 정원, 기본 소요시간(분), 색상, 사용 여부 |
| 반복 규칙 | 수업 종류, 강사, 요일, 시작 시각, 소요시간, 정원, 시작일, 종료일(선택) |
| 회차 | 날짜·시작·종료 시각, 강사, 정원, 상태(정상·휴강), 소속 반복 규칙(단발이면 없음) |

- 시간은 한국 시간(Asia/Seoul) 기준이다.
- 정원은 예약 기능이 없으므로 이번에는 안내용 표시값이다.
- 시간표·수업 종류의 조회·편집: 활성 상태이고 비밀번호 변경을 마친 관리자·서브관리자 모두 가능하다.
- 강사 여부 변경: 관리자만 가능하다(기존 직원 관리 권한과 동일). 강사 여부는 권한과 무관하므로 관리자 본인·다른 관리자·서브관리자 모두 강사로 표시할 수 있다.
- 권한은 서버 API와 DB(RLS)에서 검증하며 메뉴 숨김만으로 대신하지 않는다.

## 예외 및 정책

- 시간 겹침: 같은 강사의 휴강이 아닌 회차와 시간이 겹치면 저장을 막는다. 끝나는 시각과 시작 시각이 맞닿는 경우(10:00 종료·10:00 시작)는 겹침이 아니다.
- 강사는 강사 표시가 된 활성 직원만 지정할 수 있다.
- 사용 중지한 수업 종류는 새 수업에 고를 수 없고 기존 회차는 그대로 표시한다.
- 시작 시각은 종료 시각보다 빨라야 하고, 반복 종료일은 시작일보다 빠를 수 없다.
- 반복 수업 등록·변경 시 일부 날짜라도 겹치면 전체 저장을 막고 겹치는 날짜를 모두 안내한다.
- 지난 회차(시작 시각이 지난 회차)는 조회만 가능하다. 수정·휴강·휴강 취소·삭제를 서버에서 거부하며 '이후 전체' 변경도 지난 회차에는 적용하지 않는다.
- 휴강은 되돌릴 수 있다. 휴강 취소 시 강사 겹침을 다시 검사하고 겹치면 거부한다.
- 앞으로의 회차는 삭제할 수 있다. 반복 수업은 '이 회차만 삭제' 또는 '이 회차 이후 전체 삭제'를 고르며, 이후 전체 삭제는 반복 종료로 처리해 지난 회차는 남긴다.
- 강사 표시 해제·직원 비활성화·서브관리자 영구 삭제 시 그 직원이 맡은 앞으로의 회차 수를 확인창에 경고한다. 진행하면 회차는 남기고 강사를 비워 시간표에 '강사 미정'으로 표시한다. 지난 회차의 강사 기록은 해제·비활성화 시 유지하고, 영구 삭제 시에는 회차를 남긴 채 강사만 비운다.
- '강사 미정' 회차는 수정에서 다른 강사를 지정할 수 있고 겹침 검사 대상이 아니다.
- 반복 수업을 '이후 전체'로 변경하면 그 범위에서 휴강·삭제한 날짜는 같은 날짜의 새 회차에도 유지하고, 개별 수정한 시간·강사·정원 등은 새 값으로 덮어쓴다. 요일을 바꿔 날짜가 달라지면 이전 휴강·삭제 표시는 이어지지 않는다.
- 등록·조회할 수 있는 미래 범위는 오늘부터 1년이다. 무기한 반복 수업도 1년 앞까지의 회차를 유지하며 날이 지나면 자동으로 이어서 만든다. 1년 이후 날짜의 수업은 등록할 수 없다.

## 완료 기준

- [ ] 수업 종류를 이름·기본 정원·기본 소요시간·색상으로 등록·수정·사용 중지할 수 있고, 사용 중인 종류와 같은 이름은 저장이 거부된다.
- [ ] 관리자는 직원의 강사 여부를 바꿀 수 있고, 서브관리자의 같은 요청은 서버에서 거부된다.
- [ ] 매주 월·수 19:00 반복 수업을 종료일 없이 등록하면 시작일 이후 모든 주의 월·수에 회차가 표시된다.
- [ ] 종료일을 정한 반복 수업은 종료일 이후 회차가 표시되지 않는다.
- [ ] 특정 날짜의 단발 수업을 등록하면 해당 날짜에만 표시된다.
- [ ] 같은 강사의 기존 회차와 시간이 겹치는 수업은 저장이 거부되고 겹치는 일정이 안내된다. 맞닿는 시간은 저장된다.
- [ ] 반복 회차를 '이 회차만' 수정·휴강하면 그 회차만 바뀌고, '이후 전체'로 바꾸면 선택한 회차 이후만 바뀌며 이전 회차는 유지된다.
- [ ] 휴강 회차는 시간표에 휴강으로 구분 표시되고 강사 겹침 검사에서 제외된다.
- [ ] 휴강을 취소하면 정상 회차로 돌아오고, 그 사이 같은 강사의 겹치는 회차가 생겼다면 취소가 거부된다.
- [ ] 반복 등록 중 한 날짜라도 겹치면 아무 회차도 저장되지 않고 겹치는 날짜 목록이 안내된다.
- [ ] 지난 회차의 수정·휴강·삭제 요청은 화면에 버튼이 없고 직접 API 요청도 거부된다.
- [ ] 앞으로의 회차를 '이 회차만' 삭제하면 그 회차만 사라지고, '이후 전체' 삭제하면 선택 회차부터 사라지며 이전 회차는 남는다.
- [ ] 앞으로 맡은 회차가 있는 강사를 해제·비활성화·삭제하면 확인창에 회차 수가 경고되고, 진행 후 해당 회차는 '강사 미정'으로 표시되며 삭제되지 않는다.
- [ ] PC·태블릿에서는 주간 그리드, 모바일에서는 날짜별 목록이 표시되고 주 이동·오늘 이동·수업 종류·강사 필터가 동작한다.
- [ ] 비로그인·비활성·비밀번호 변경 전 직원의 화면 접근과 API·DB 직접 요청이 거부된다.
- [ ] 강사 표시가 없거나 비활성인 직원, 사용 중지한 수업 종류를 직접 요청으로 지정해도 저장되지 않는다.
- [ ] '이후 전체' 변경 후에도 그 범위에서 휴강·삭제한 같은 날짜는 휴강·삭제 상태로 남고, 개별 수정한 회차는 새 값으로 바뀐다.
- [ ] 오늘부터 1년 이후 날짜의 수업 등록은 거부되고, 무기한 반복 수업은 날이 지나도 1년 앞까지 회차가 표시된다.
- [ ] 관리자는 본인·다른 관리자·서브관리자 모두의 강사 여부를 바꿀 수 있다.

## 미결 질문

- 없음. 테이블·컬럼·반복 회차 저장 방식 등 구현 상세는 작업계획에서 정한다.

## 합의 및 변경 이력

- 2026-10-22: 사용자와 1차 범위 합의. GX 그룹수업 위주, 회원 예약 제외(수업·시간표만), 강사는 기존 직원 계정에 강사 여부 표시(역할 추가 없음), 반복·단발 수업 모두 지원, 시간표 편집은 관리자·서브관리자, 공간 관리 제외, 같은 강사 시간 겹침은 등록 차단, 수업 종류 별도 등록, 반복 수정은 '이 회차만/이후 전체', 주간 그리드+모바일 목록, 반복 종료일은 선택(무기한 가능). 기획 미확정.
- 2026-10-22: 세부 정책 합의. 지난 회차는 조회만, 휴강 취소(겹침 재검사)와 앞으로의 회차 삭제 허용, 강사 해제·비활성화·삭제 시 경고 후 '강사 미정' 처리, 반복 등록 중 일부 겹침은 전체 차단. 기획 미확정.
- 2026-10-22: 수업 종류 관리는 관리자·서브관리자 허용, 대시보드 '오늘의 수업'은 제외, LNB 메뉴 1개(`/classes`)와 화면 내 시간표·수업 종류 탭으로 합의. 미결 질문 해소, 사용자 기획 확정 대기.
- 2026-10-22: 사용자가 기획을 확정하고 작업계획 작성을 요청했다. 작업계획 검토 중 나온 세부 정책을 합의해 반영: '이후 전체' 변경 시 휴강·삭제 날짜 유지·개별 수정 덮어씀, 미래 등록·조회 범위 1년(무기한 반복은 자동 연장), 관리자 포함 모든 직원 강사 표시 가능.
- 2026-10-22: 사용자 요청 변경안. 수업 종류에 그 수업을 맡는 담당 강사 1명을 둔다(모든 활성 직원 중 선택, 수업 추가 시 자동 채움). 그 결과 직원별 '강사 여부' 표시와 직원 관리의 강사 지정·해제는 없앤다.
- 2026-10-22: 논의 결과 담당 강사 변경안을 철회했다. 수업마다 강사를 고르고 시간표 강사 필터가 실제 회차 강사 기준으로 동작하므로 추가 기능이 필요 없다고 사용자가 판단했다. 기획은 기존 확정 내용 그대로이며, 사용자는 기능 범위를 현재 상태로 마무리하기로 했다.
