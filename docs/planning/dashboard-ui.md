# 기본 대시보드 UI 기획

- 기능 ID: dashboard-ui
- 상태: 확정
- 최종 갱신: 2026-10-22
- 작업계획: [작업계획](../plans/dashboard-ui.md)
- 현재 기능 문서: [기능 문서](../features/dashboard-ui.md)

## 목적 및 사용자

PCOME CRM 관리자가 사용할 공통 화면 구조와 대시보드 첫 화면을 만든다. 이후 로그인·서브 관리자 관리·업무 기능을 붙일 수 있는 UI 기반을 마련한다.

## 범위

- Mantine 기반 공통 레이아웃: 사이드바, 상단바, 본문.
- PC LNB 접기·펼치기: 접으면 아이콘만 표시하고 본문을 넓히며 메뉴 이름은 툴팁과 접근성 이름으로 제공한다. 새로고침 시 펼침 상태로 시작한다.
- 데스크톱·태블릿·모바일 반응형 화면과 모바일 메뉴 열기·닫기.
- 대시보드 첫 화면의 제목, 안내, 데이터 연결 전 빈 상태.
- 현재 위치 및 키보드 포커스 표시.
- 제외: 로그인, 권한 검사, 관리자 CRUD, 고객·일정 기능, API·DB 연결, 실제 통계, 테마 전환.

## 사용자 흐름

1. `/`에 접속해 대시보드와 공통 메뉴를 확인한다.
2. 작은 화면에서는 메뉴 버튼으로 사이드바를 열고 닫는다.
3. 준비 중인 메뉴는 비활성 표시로 향후 기능임을 구분한다.

## 화면 및 동작

- 디자인: 브랜드 사이트의 오렌지·차콜·흰색을 기반으로 밝은 회색 본문, 흰색 패널, 차콜 사이드바, 오렌지 강조색을 사용한다. 아래 색상안은 사용자 확인 완료이며 코드에는 미반영이다.
- 사이드바: PCOME CRM 브랜드, 활성 메뉴 `대시보드`, 비활성 메뉴 `관리자 관리`와 `준비 중` 표시. 업무 메뉴는 해당 기능 기획 시 추가한다.
- 상단바: 현재 화면명. 모바일에서 메뉴 버튼 노출. 미구현 검색·알림·프로필 조작은 배치하지 않는다.
- 본문: `대시보드` 제목, 짧은 안내, `아직 연결된 업무 데이터가 없습니다` 빈 상태. 임의의 통계 숫자나 가짜 고객 정보는 표시하지 않는다.
- 현재 단계에는 비동기 요청이 없어 로딩·요청 실패 UI는 구현하지 않는다. 실제 데이터 연결 작업에서 정의한다.

## 데이터 및 권한

정적 화면만 제공하며 인증된 사용자로 가장하지 않는다. 현재 공개 `/` 페이지에 표시한다. 계정 정보와 권한은 후속 기획에서 정의한다.

## 예외 및 정책

- 준비 중인 메뉴는 이동하지 않고 비활성 상태와 이유를 표시한다.
- 모바일 메뉴는 닫기 버튼·배경 클릭·Escape로 닫을 수 있다.
- 메뉴 열림 상태에서 키보드 포커스를 관리하고 닫으면 열기 버튼으로 복귀한다.

## 2026-10-22 공통 앱 프레임 전환 합의

사용자 확정: LNB와 메인 화면을 차콜 외부 프레임·공통 상단바로 감싼다. PC 토글을 공통 상단바 고정 위치로 옮기고 모바일 메뉴 버튼도 같은 영역에 둔다. 내부 상단바는 화면 위치 표시를 유지한다. 별도 세로 아이콘 바는 추가하지 않는다. 기존 색상·16px 아이콘·버튼 크기·200ms 전환 유지.

작업: Dashboard 구조와 CSS 수정 → 기존 경계 위치 테스트를 고정 위치 검증으로 변경 → 전체 E2E·린트·타입 검사·Webpack 빌드 → 1440·768·390px 화면과 hover·콘솔·네트워크 확인 → 자체 리뷰·문서 반영. 성공 기준은 토글 위치가 접힘·펼침에 동일하고 두 내부 영역이 프레임 안에 배치되며 가로 넘침·모바일 메뉴 회귀가 없는 것이다.
