# 기본 대시보드 UI

- 기능 ID: dashboard-ui
- 상태: 완료
- 최종 갱신: 2026-10-22
- 기획: [기획](../planning/dashboard-ui.md)
- 작업계획·검증 이력: [계획](../plans/dashboard-ui.md)

## 화면 및 경로

`/`는 PCOME CRM 대시보드다. 외부 여백·테두리·바깥 반경 없이 전체 화면을 채우는 차콜 앱 프레임과 높이 48px의 공통 상단바가 LNB·메인 화면을 감싼다. 프레임은 화면 높이에 맞추고 상단바·LNB는 프레임 기준으로 배치한다. 본문 영역만 내부 스크롤되므로 상단바와 내부 화면 경계가 어긋나지 않는다. PC 토글과 모바일 메뉴 버튼은 공통 상단바에 있다. 본문 위의 흰 위치 표시 바(브레드크럼)는 2026-10-22 사용자 요청으로 제거해, 본문이 공통 상단바 바로 아래에서 시작한다. 차콜 LNB, 밝은 회색 본문, 오렌지 포인트를 사용한다. 페이지 제목과 설명은 한 줄(제목 22px·설명 13px, 좁으면 줄바꿈)로 표시하고, 설명은 `Dashboard`의 `description` prop으로 화면마다 지정한다. 영문 eyebrow 문구는 2026-10-22 사용자 요청으로 제거했다. 본문에는 '이번 주 수업 현황' 패널([대시보드 수업 차트](../planning/dashboard-charts.md))을 표시한다: 이번 주(월~일, 서버 기준 한국 날짜) 요일별 수업 수 세로 막대와 강사별 담당 수업 수 가로 막대(많은 순, '강사 미정' 포함)를 정상·휴강으로 쌓아 보여준다. 막대 끝 합계·툴팁·범례와 화면에 보이지 않는 표로 수치를 제공하고, 로딩 스켈레톤·오류와 다시 시도·수업이 없을 때 빈 상태와 '수업 시간표' 링크를 둔다. 기존 회차 조회 API를 화면에서 집계하며(`src/lib/classes/stats.ts`) 차트는 `@mantine/charts`로 그린다. 회원 데이터는 아직 없으며 실제 직원 프로필은 공통 헤더에 표시한다.

- 대시보드 메뉴: 현재 페이지 링크(`/`), 활성 상태 제공.
- 관리자 관리: 관리자에게만 `/admin/staff` 링크를 표시한다. 서브관리자에게는 표시하지 않는다.
- 992px 이상: 248px 고정 LNB. 공통 상단바의 고정 아이콘 버튼으로 88px 아이콘 LNB로 접고 펼친다. 접힌 메뉴는 hover 툴팁과 접근성 이름을 제공한다.
- 992px 미만: 고정 LNB 대신 상단 메뉴 버튼으로 280px Mantine Drawer를 연다. 닫기 버튼·배경 클릭·Escape로 닫는다. 포커스 트랩과 닫은 뒤 열기 버튼으로 복귀를 제공한다.
- PC 접힘 상태는 React 메모리에만 보관한다. 새로고침하면 펼쳐진 상태로 시작한다. PC LNB 너비·본문 왼쪽 여백·토글 아이콘 회전은 200ms ease로 전환하며 `prefers-reduced-motion: reduce`에서는 전환을 끈다. 모바일 메뉴는 별도 상태이며 PC 접힘 상태를 변경하지 않는다.
- 본문 건너뛰기 링크, 키보드 포커스 표시, 장식 SVG의 접근성 제외를 적용한다.

## 버튼·아이콘 크기

메뉴 및 조작 아이콘은 16px, 메뉴 안쪽 여백은 상하 10px·좌우 12px다. 공통 상단바에서 PC LNB 접기·펼치기 버튼(28×28px)을 제공하고 접근성 이름과 툴팁으로 동작을 설명한다. 접힘·펼침 상태에 관계없이 바깥 공통 상단바의 동일한 위치에 배치한다. 모바일 열기 버튼은 32×32px, 닫기 버튼도 32px이며 hover·active에서는 #333 배경과 흰 X를 유지한다. 메뉴 항목의 최소 높이는 44px다. 빈 상태 장식 아이콘은 24px, 배경은 56px다.

## 데이터·권한·예외

Supabase의 활성 직원 인증이 필요한 화면이다. 미인증·직원 프로필 없음·비활성 계정은 로그인 화면으로 이동한다. 최초·임시 비밀번호 계정은 `/password`로 이동한다. 직원 이름·역할은 실제 프로필에서 표시하며 회원·통계 데이터는 아직 연결하지 않았다. 현재 인증·오류 정책은 [직원 인증 기능](admin-auth.md)을 참고한다.

## 색상 정책

공통 상단바와 LNB는 모두 `#1D1D1D`이며 사이의 구분선은 없다. 하나의 차콜 영역으로 이어지고 밝은 본문만 구분한다.

[브랜드 사이트](http://patricksoutcome.com/wp/)에서 확인한 오렌지 `#F25634`, 차콜 `#1D1D1D`, 흰색을 기반으로 한다. 주요 조작색은 대비를 높인 `#D63E20`, 연한 강조 배경은 `#FFF0EB`, 본문 배경은 `#F7F7F8`, 주 텍스트는 `#28262B`, 설명은 `#565656`이다. Mantine brand 10단계를 테마에 등록하고 primaryShade 6으로 지정한다. 실제 로고 파일은 사용하지 않으며 화면에는 텍스트 및 CSS P 마크를 표시한다.

Drawer는 portal로 렌더링되므로 브랜드 변수를 Drawer에도 선언하고 포커스 스타일도 별도로 적용한다.

## 검증 및 제한

2026-10-22 Chromium에서 1440×900·768×900·390×900 화면을 캡처해 검토했다. PC LNB 실제 접기·펼치기를 인앱 브라우저에서도 확인했다. Chromium E2E 11개와 린트·타입 검사·Webpack 빌드를 통과했다. Turbopack 빌드는 환경의 내부 포트 생성 권한 제한으로 실패했다. 상세 실행 결과 및 수정 이력은 작업계획에 기록한다. Firefox·Safari·실물 모바일 기기는 미검증이다. 배포는 수행하지 않았다.

LNB 여백: PC 상하 20px·좌우 16px, 로고와 메뉴 영역 간격 24px. 접힌 LNB도 같은 상단 패딩과 24px 메뉴 간격을 사용한다. 모바일 Drawer의 별도 간격은 유지한다.

## GitHub 링크·파비콘

공통 상단바의 GitHub 링크·WORKSPACE 우측 장식은 후속 사용자 요청으로 제거했다. 현재 오른쪽 영역은 아래 로그인 계정 UI를 사용한다.

`src/app/icon.svg`는 LNB 오렌지 P 마크를 바탕으로 만든 32px 아이콘이며 Next.js 파일 규약으로 자동 연결된다. `src/app/favicon.ico`도 같은 SVG에서 생성한 32px PNG를 포함한 ICO로 교체했다. 기본 Next.js 파비콘을 제거했으며 CSS 로고와 SVG 파비콘은 별도 구현이므로 로고 변경 시 둘을 함께 갱신한다.

2026-10-22 GitHub 링크 주소·새 탭·우측 배치·SVG 및 ICO 응답 테스트 추가 후 Chromium 12개, 린트·타입 검사·Webpack 빌드 통과. PC 1440×900·모바일 390×900 캡처 및 파비콘 모양 검토. 실제 외부 저장소 이동은 수행하지 않았다.

접힌 LNB의 메뉴 버튼은 36×36px 정사각형이며 아이콘은 버튼 중앙, 로고와 버튼은 88px LNB의 가로 중앙에 배치한다. 펼친 상태와 모바일 Drawer의 크기는 유지한다.

## 직원 인증 연동 후 변경 (2026-10-22)

공개 대시보드에서 활성 직원 전용 화면으로 전환했다. 관리자에게만 /admin/staff 메뉴를 제공한다. 공통 헤더에는 직원 이름·역할·비밀번호 변경·로그아웃을 표시한다. 관리자 관리와 /도 같은 Dashboard 프레임을 사용한다. 계정 조작은 48px 차콜 공통 상단바로 이동했으며 내부 화면 헤더는 모바일 66px를 사용한다(내부 화면 헤더는 2026-10-22 제거). 회원 업무 데이터는 아직 없어 본문 빈 상태는 유지한다(2026-10-22 수업 현황 차트로 대체). 현재 인증·권한 동작과 최신 검증은 [직원 인증 기능](admin-auth.md)과 [작업계획](../plans/admin-auth.md)을 기준으로 한다.


## 상단바 계정 UI 후속 보정 (2026-10-22)

`dashboard.tsx`의 공통 상단바 오른쪽에 로그인한 직원의 사용자 아이콘·이름·권한과 로그아웃을 배치한다. 관리자/서브관리자는 실제 staff.role에 따라 표시한다. 이름 링크는 `/password`로 연결되며 접근성 이름·툴팁에 전체 이름·권한·비밀번호 변경 동작을 담는다. 긴 이름은 말줄임하고 모바일 권한 표시만 숨긴다. 내부 흰색 헤더는 현재 경로만 표시한다(2026-10-22 제거).

`LogoutButton`은 선택적인 className/errorClassName으로 차콜 스타일·오류 안내 위치를 지원한다. 비밀번호 변경 화면에서는 기존 기본 스타일을 유지한다. 로그아웃 요청 중 버튼을 잠그며 실패 시 상단바 아래 안내와 재시도를 제공한다. 인증 API와 로그아웃 범위는 변경하지 않았다.

관련 검증·리뷰는 [UI 개선 작업계획](../plans/staff-ui.md)에 기록한다.


## 페이지 로딩 및 권한 배지 (2026-10-22)

페이지 이동에는 별도 로딩 효과를 표시하지 않는다. 스피너·문구·블러·딤 필터를 모두 제거했으며 목적지 응답을 기다리는 동안 기존 화면을 유지한다. `src/app/loading.tsx`, `components/common/page-loading.tsx`, `link-loading.tsx`, `loading.module.css`는 제거했다. 모바일 메뉴는 항목 선택 시 닫히며 메뉴·계정 링크·비밀번호 화면 복귀는 Next Link 기본 이동을 사용한다. 목록 API 조회용 스켈레톤·새로고침 로딩은 유지한다.

2026-10-22 연속 간소 UI 보정 검증: Chromium PC·모바일 이동 및 비밀번호 화면 복귀 3개 통과(7.8초). 지연된 목적지 응답에서 기존 화면·이동 효과 없음·정상 전환·모바일 메뉴 닫힘·콘솔/네트워크 확인, PC 캡처 1장 시각 검토. 사용자의 커밋 지시 후 린트·타입 검사·Webpack 빌드 통과. 실제 전체 diff와 새 테스트 내용을 최종 리뷰했고 삭제 컴포넌트 참조 없음·목록 로딩 유지·문서 일치를 확인했다. 미해결 문제 없음. 사용자 최종 승인·완료 처리.

계정 권한은 공통 `RoleBadge`로 표시한다. 상단바 모바일 배지 숨김·이름 말줄임·로그아웃은 기존 동작을 유지한다. 검증은 [로딩·목록 조작 계획](../plans/loading-staff-controls.md)을 참고한다.
