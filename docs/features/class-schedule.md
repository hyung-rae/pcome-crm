- [확정 기획](../planning/class-schedule.md) · [작업계획·검증 기록](../plans/class-schedule.md) · [저장 방식 결정](../decisions/class-schedule-storage.md) · [ERD](../architecture/erd.md)

## 기능 요약 및 진입점

직원(관리자·서브관리자)이 GX 그룹수업의 종류와 주간 시간표를 등록·조회·변경한다. LNB '수업 시간표'(`/classes`)는 모든 활성 직원에게 보인다. 화면 안에서 '시간표'와 '수업 종류' 탭을 전환한다. 강사 지정은 관리자 화면(`/admin/staff`)에서 한다.

## 현재 동작

### 수업 종류

- 이름(1~30자), 기본 정원, 기본 소요시간, 색상(고정 8종)을 등록·수정한다. 화면에서는 정원(1·5·10·15·20명)·소요시간(10~120분, 5분 단위)을 칩으로, 색상은 해당 색 배경의 카드(Radio.Card)로 고른다. 기존 값이 칩 목록에 없으면 그 값도 칩으로 함께 보여준다. 서버 허용 범위는 정원 1~100명, 소요시간 10~240분(5분 단위)이다. 사용 중지와 다시 사용을 지원하며 삭제는 없다.
- 사용 중인 종류끼리는 이름이 같을 수 없다. 대소문자와 앞뒤 공백은 무시한다. 사용 중지한 종류와 같은 이름은 새로 등록할 수 있지만, 그러면 이전 종류는 다시 사용할 수 없다.
- 사용 중지한 종류는 새 수업에 고를 수 없다. 기존 회차는 그대로 표시한다.

### 시간표

- 768px 이상은 월~일 × 시간 주간 그리드(1시간 64px), 768px 미만은 날짜별 목록이다. 둘 다 그리고 CSS로 하나만 보여 첫 렌더링에서 화면이 바뀌지 않는다. 그리드는 08:00~23:00을 기본으로 보여주고(마지막 23:00 라벨 포함), 범위를 벗어난 회차가 있으면 범위를 넓힌다. 같은 시간대의 여러 수업은 나란히 배치한다.
- 이전 주·다음 주·오늘 이동을 제공한다. 다음 주 이동은 미래 범위(오늘부터 1년)가 끝나는 주까지만 가능하다. 수업 종류·강사(강사 미정 포함) 필터(Mantine Select)를 제공하며, 필터는 주 이동과 같은 줄의 '수업 추가' 버튼 왼쪽에 둔다. 탭은 Mantine 기본(`default`, 밑줄) 스타일이며, '수업 종류' 탭에는 사용 중인 종류 수를 숫자 뱃지로 표시한다(숨겨진 동안은 마지막으로 불러온 값 유지). 768px 이상 그리드는 본문에 남은 높이만큼만 차지하고 그 안에서만 스크롤하며(요일 행 고정, 최소 320px), 이번 주를 볼 때 현재 시각이 그리드 범위 안이면 표시한다: 주 전체에 연한 가로선, 오늘 열에는 진한 선과 점, 시간 열에는 'HH:MM' 알약(가려지는 정시 라벨은 숨김). 1분마다 갱신한다. 이번 주를 열면 현재 시각 1시간 전 위치로, 다른 주는 08:00 위치로 스크롤한다(Mantine Schedule의 startScrollTime 방식).
- 주간 그리드의 회차 블록은 수업명(휴강이면 '휴강' 태그 포함)만 수업 종류 색상과 함께 표시한다. 짧은 블록에서 잘리기 때문이며, 시간·강사·정원은 마우스를 올리면 나오는 툴팁과 접근성 이름·상세에 있다. 날짜별 목록은 수업명·시간·강사·정원을 표시하고, 강사가 없으면 '강사 미정'을 텍스트로 표시한다. 휴강은 흐리게 + '휴강' 태그로 색에만 의존하지 않는다. 시작 시각이 지난(진행 중 포함) 회차는 그리드·목록 모두 더 흐리게(불투명도 0.45) 표시하고 접근성 이름 끝에 '지난 수업'을 붙인다. 화면을 열어 둔 동안에도 1분마다 반영하고, 상세도 같은 기준으로 조회 전용이 된다(서버도 409로 막는다).
- 수업 추가: 수업 종류·강사(필수)·단발/매주 반복·날짜(반복이면 시작일)·반복 요일·종료일(선택, 비우면 계속 반복)·시작 시각(5분 단위)을 입력하고 소요시간·정원은 수업 종류와 같은 칩(목록에 없는 기존 값은 칩으로 추가)으로 고른다. 수업 종류를 고르면 정원·소요시간 기본값이 채워진다. 반복 요일은 직접 고르기 전까지 시작일의 요일을 따른다.
- 같은 강사의 휴강이 아닌 회차와 시간이 겹치면 저장하지 않고 Modal 안에 겹치는 일정(최대 10건 + 나머지 건수)을 보여준다. 끝과 시작이 맞닿는 시간은 허용한다. 반복 등록은 한 날짜라도 겹치면 아무 회차도 저장하지 않는다.
- 회차를 누르면 상세(일시·강사·정원·반복·상태)가 열린다. 앞으로의 회차는 수정·휴강/휴강 취소·삭제를 할 수 있다. 반복 회차는 '이 회차만/이 회차 이후 전체' 범위를 고른다. 시작 시각이 지난 회차는 조회만 된다.
- '이후 전체' 수정은 선택한 회차부터 새 반복 규칙으로 바꾼다. 폼은 반복 규칙 값(개별 수정한 회차 값이 아님)으로 시작한다. 그 범위의 기존 회차 상태(휴강·삭제, 전체 휴강 중 하루 되살린 정상 회차 포함)는 같은 날짜에 유지하고, 개별 수정한 시간·강사·정원은 새 값으로 덮어쓴다. 과거로 옮겨 이미 지난 날짜는 다시 만들지 않는다. 이전 회차는 바뀌지 않는다. 요일을 바꿔도 '이후 전체 휴강'은 이어진다.
- '이후 전체' 휴강은 이후에 새로 만들어지는 회차에도 휴강을 적용한다. '이후 전체' 휴강 취소는 선택한 날짜 이후의 휴강을 모두 정상으로 돌리며, 회차마다 그 회차의 강사 기준으로 겹침을 다시 검사한다. '이후 전체' 삭제는 반복을 선택 회차 전날로 끝낸다. 첫 회차부터 삭제·변경해 반복 규칙이 없어지면 이미 지난 회차는 단발 기록으로 남긴다.
- 성공 시 기존 토스트 패턴으로 수업 등록·수정, 휴강 처리·취소, 수업 삭제, 수업 종류 등록·수정, 사용 중지·다시 사용 완료를 알린다. 조회 실패 시 오류와 다시 시도 버튼을 보여준다.

### 직원 관리 연동

- 직원 목록에 '강사' 열(강사 배지)을 추가했다. 더보기 메뉴의 '강사 지정/해제'는 관리자 본인·다른 관리자 행을 포함한 모든 행에 있다. 관리자 행에는 이 항목만 있다.
- 회차 수 조회에 실패해도 직원 목록은 열리고, 강사인 직원은 '수를 확인하지 못했다'는 경고를 띄운다.
- 앞으로 맡은 회차가 있는 직원을 강사 해제하거나 비활성화하면, 바로 바꾸지 않고 회차 수를 보여주는 확인 Modal을 띄운다. 삭제 Modal에도 같은 경고를 표시한다. 회차가 없으면 기존처럼 바로 바뀐다.
- 진행하면 앞으로의 회차는 남기고 강사만 비워 '강사 미정'이 된다. 해제·비활성화 시 지난 회차의 강사 기록은 유지되고, 영구 삭제 시에는 지난 회차의 강사도 비워진다. 다시 활성화하거나 강사로 다시 지정해도 비워진 회차가 자동으로 복구되지 않는다.

## 데이터 및 권한

- 테이블: `class_types`, `class_series`(반복 규칙), `class_sessions`(회차), `staff.is_instructor`. 상세 구조는 [ERD](../architecture/erd.md)에 있다.
- 회차는 오늘부터 1년 앞까지 DB에 미리 만든다. 모든 시간표 API가 먼저 `class_extend_series`를 호출해 무기한·장기 반복의 회차를 채운다. 이유는 [저장 방식 결정](../decisions/class-schedule-storage.md)에 있다.
- 강사 시간 겹침은 `class_sessions`의 제외 제약(`btree_gist`)이 최종으로 막는다. 쓰기 RPC는 advisory lock으로 한 번에 하나씩 처리하고, 저장 전에 겹치는 회차 목록을 돌려준다.
- `/classes`는 `src/proxy.ts` 경로 목록에 포함되어 세션 쿠키가 갱신된다.
- 쓰기 RPC(`class_create`·`class_update`·`class_set_status`·`class_delete`·`class_upcoming_counts`·`class_extend_series`)는 `service_role`만 실행할 수 있다. 서버 API가 `requireStaff()`로 활성·비밀번호 변경 완료 직원인지 확인한 뒤 서버 관리 키로 호출한다.
- RLS: 세 테이블 모두 유효 세션을 가진 활성·변경 완료 직원만 SELECT할 수 있다. `anon`은 권한이 없고, 일반 사용자에게는 쓰기 권한이 없다.
- 조회·편집: 관리자·서브관리자 모두. 강사 여부 변경: 관리자만(`PATCH /api/staff/[id]` `action: instructor`).
- 강사 제외 처리는 staff 트리거 `private.staff_release_classes`가 한다. 강사·작성자 FK는 `ON DELETE SET NULL`이다.
- 시간은 `Asia/Seoul` 기준이며 `timestamptz`로 저장한다. 수업은 자정을 넘길 수 없다(24:00 종료는 허용).

## 예외 및 제한

- RPC 결과 코드 → HTTP 상태: `type_unavailable`·`instructor_unavailable`·`out_of_range`·`no_dates`·`invalid`·`start_in_past`(이미 지난 시작 시각 입력) 400, `past`·`conflict` 409, `not_found` 404. 동시 요청이 제외 제약에 걸리면(`23P01`) 409로 응답한다. 시간표 조회 중 회차 확장이 실패해도 조회는 계속한다.
- 1년 범위 확장은 시간표 API가 호출될 때 일어난다. 오래 아무도 쓰지 않으면 다음 사용 때 한꺼번에 채워진다.
- '이후 전체' 휴강 취소는 그 전에 하루씩 따로 잡은 휴강도 함께 정상으로 돌린다.
- 직원 목록의 회차 수는 목록을 불러온 시점의 값이다.
- 회원 예약·출석, PT, 공간, 월간 보기, 알림, 대시보드 '오늘의 수업'은 범위 밖이다.
