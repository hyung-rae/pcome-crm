## 구현 방향 및 영향 범위

Mantine 기반으로 `/` 시작 화면을 대시보드로 교체한다. 차콜 사이드바, 흰 상단바, 밝은 회색 본문과 오렌지 포인트를 사용한다. 활성 대시보드 메뉴와 준비 중인 관리자 관리 메뉴, 데이터 연결 전 빈 상태를 제공한다. 로그인·계정 관리·실제 통계는 포함하지 않는다.

- `src/theme.ts`: 확정 색상과 Mantine 색상 단계, 주요 버튼 대비.
- `src/app/page.tsx`: 대시보드 진입.
- `src/components/dashboard/`: 공통 레이아웃·모바일 메뉴와 CSS Modules 신설.
- `src/app/globals.css`, 필요 시 `src/app/layout.tsx`: 전역 스타일·메타데이터.
- `package.json`, 잠금 파일, Playwright 설정 및 `tests/`: E2E 테스트 도입. 개발 의존성으로 `@playwright/test`를 추가하고 테스트 스크립트를 정의한다.
- 문서: 기능 문서 신설, 시스템 구조·색인·현황·실행 안내 갱신.
- DB·API·인증·배포 변경 없음.

### 자동 검증

- 도구: Playwright E2E. 테스트 파일: `tests/dashboard.spec.ts`.
- 검증 명령: `npm run test:e2e`, `npm run lint`, `npm run typecheck`, `npm run build`.
- `PLAYWRIGHT_BASE_URL=http://localhost:3002 npm run test:e2e`: Chromium 8개 테스트 통과(2.8초).
- `npm run lint`, `npm run typecheck`: 최종 통과.
- `npm run build`: Turbopack CSS 처리 중 내부 포트 생성 권한 제한으로 실패. `npm run build -- --webpack`: 최종 통과, `/` 정적 페이지 생성.
- 초기 타입 검사와 빌드가 `.next/types`를 동시에 생성·정리하여 타입 검사 실패. 이후 순차 실행하여 통과. 빌드·타입 검사는 순차 실행한다.
- 최초 모바일 테스트에서 닫힘 전환 중 재열기로 포커스 확인 실패. 각 닫힘 뒤 포커스 복귀와 열림을 기다리도록 테스트 보완, 재실행 통과.
- 시각 검토에서 Drawer portal에 브랜드 변수가 전달되지 않는 문제 발견. Drawer에 변수·포커스 스타일 적용, 메뉴 완전 열림 위치와 브랜드 배경색 회귀 테스트 추가 후 전체 통과.
- 기본 빌드가 실행 환경 제한으로 실패하면 사유를 기록하고 Webpack 빌드를 추가 검증한다.

## 2026-10-22 공통 앱 프레임 전환 합의

사용자 확정: LNB와 메인 화면을 차콜 외부 프레임·공통 상단바로 감싼다. PC 토글을 공통 상단바 고정 위치로 옮기고 모바일 메뉴 버튼도 같은 영역에 둔다. 내부 상단바는 화면 위치 표시를 유지한다. 별도 세로 아이콘 바는 추가하지 않는다. 기존 색상·16px 아이콘·버튼 크기·200ms 전환 유지.

작업: Dashboard 구조와 CSS 수정 → 기존 경계 위치 테스트를 고정 위치 검증으로 변경 → 전체 E2E·린트·타입 검사·Webpack 빌드 → 1440·768·390px 화면과 hover·콘솔·네트워크 확인 → 자체 리뷰·문서 반영. 성공 기준은 토글 위치가 접힘·펼침에 동일하고 두 내부 영역이 프레임 안에 배치되며 가로 넘침·모바일 메뉴 회귀가 없는 것이다.
